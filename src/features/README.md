# Feature domains

This folder groups the app by business domain so each area can grow without turning the codebase into a generic component dump.

- `auth`: registration, login, sessions
- `nasa`: NASA search and API integration
- `collections`: user collections and saved items
- `enrichment`: AI-generated context and descriptions
- `tags`: manual and suggested tags
- `search`: filtering and future semantic search
- `export`: PDF or presentation export flows
